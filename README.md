# Heritage Gift Wala

Online store for [Heritage Gift Wala](https://heritagegiftwala.in), a gift shop at Shlok Plaza, Rajmahel Road, Patan.

| Folder | What it is |
| --- | --- |
| `storefront/` | The shop **and** the owner's control panel (Next.js 16 + Supabase). Deploy on Vercel with **Root Directory = `storefront`**. See [storefront/README.md](storefront/README.md). |
| `design/pipeline/` | Scripts that turned the shop's phone photos into the studio product shots. |

Going live (Supabase + Vercel): [docs/DEPLOY.md](docs/DEPLOY.md). The shop owner's day-to-day guide: [docs/OWNER-GUIDE.md](docs/OWNER-GUIDE.md).
