# Heritage Gift Wala

Online store for [Heritage Gift Wala](https://heritagegiftwala.in), a gift shop on University Road, Patan.

| Folder | What it is |
| --- | --- |
| `storefront/` | The customer site (Next.js 16). Deploy on Vercel with **Root Directory = `storefront`**. Setup and Medusa wiring are in [storefront/README.md](storefront/README.md). |
| `design/pipeline/` | Scripts that turned the shop's phone photos into the studio product shots. |

The Medusa backend (Render + Supabase) will live alongside in `backend/`.
